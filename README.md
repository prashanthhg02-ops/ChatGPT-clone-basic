# ChatGPT-clone-basic
Created a responsive ChatGPT-style chat app using browser-based AIML rules. It supports wildcard replies, prompt suggestions, saved conversations, and a mobile sidebar. Edit the bot’s patterns and responses in aiml.xml; chat matching is handled in app.js.

Try it at http://localhost:8000. This is a rule-based chatbot, not a generative AI model. JavaScript, AIML XML, workspace diagnostics, and browser interactions
